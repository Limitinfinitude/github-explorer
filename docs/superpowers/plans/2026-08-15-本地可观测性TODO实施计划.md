# 本地可观测性 TODO 实施计划

> 本计划用于按任务逐项推进本地可观测性改造，使用复选框记录状态。

**目标：** 在不改变原始任务事实的前提下，让本地观测指标可版本化、可查询，并且读取成本可控。

**架构：** 保留任务、事件、工具调用、产物和变更集等原始事实；新增按任务和指标版本索引的 `agent_task_metrics` 派生快照。读取时优先使用匹配版本的快照，旧任务再执行轻量重算。服务端提供运行记录筛选，前端提供紧凑的筛选栏。

**技术栈：** Python、SQLite、FastAPI、React、TypeScript、pytest、Node 内置测试。
