# GitHub探索者 - 产品需求文档

## 1. 产品概述

**GitHub探索者** 是一个帮助开发者发现热门开源项目的工具。它能搜索GitHub项目，分析星数增长趋势，并用通俗易懂的语言解释项目用途，让技术小白也能快速了解开源生态。

## 2. 目标用户

- 想了解开源项目的技术小白
- 寻找优质项目的开发者
- 跟踪技术趋势的学习者

## 3. 核心功能

### 3.1 关键词搜索
- 输入关键词搜索GitHub项目
- 支持语言、时间范围筛选
- 展示项目基本信息（名称、描述、星数、Fork数）

### 3.2 趋势分析
- 显示项目近期星数增长（7天/30天）
- 识别"飙升项目"（星数快速增长）
- 趋势可视化图表

### 3.3 AI解读
- 用小白能懂的话解释项目
- 突出项目亮点和适用场景
- 给出学习建议

### 3.4 本地启动
- 一键克隆项目到本地
- 自动检测项目类型并给出启动命令
- 生成启动脚本

## 4. 技术架构

```
┌─────────────────────────────────────────────┐
│                  前端 (HTML/JS)              │
│  搜索框 │ 结果列表 │ 趋势图表 │ 启动按钮   │
└─────────────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────┐
│              后端 (Python FastAPI)           │
├─────────────────────────────────────────────┤
│  API模块  │  AI模块  │  本地启动模块        │
└─────────────────────────────────────────────┘
                      │
        ┌─────────────┼─────────────┐
        ▼             ▼             ▼
   GitHub API    Claude API    本地Git
```

## 5. 技术选型

| 组件 | 技术 | 理由 |
|------|------|------|
| 后端 | Python FastAPI | 异步支持好，开发快 |
| 前端 | HTML + Vanilla JS | 简单直接，小白友好 |
| GitHub交互 | GitHub REST API | 官方API，稳定可靠 |
| AI解读 | Claude API | 解释能力强 |
| 数据存储 | SQLite | 轻量，无需额外配置 |
| 图表 | Chart.js | 轻量级图表库 |

## 7. API设计

### 7.1 搜索项目
```
GET /api/search?q={keyword}&lang={language}&period={period}
```

### 7.2 获取趋势
```
GET /api/trending?period=7d
```

### 7.3 AI解读
```
POST /api/explain
Body: { "repo": "owner/name" }
```

### 7.4 本地启动
```
POST /api/clone
Body: { "repo": "owner/name" }
```
