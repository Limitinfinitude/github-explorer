## 3. 已验证共识(多 harness 共同确认)

1. **外部判分方向正确**:SWE-agent(SWE-bench)、OpenHands(fake_user)、我们(判分脚本)
   都是「判分器与 agent 解耦、判分输入只有产出物、干净环境跑测试」。我们的机制已验证。
2. **缓存命中靠前缀稳定**:Goose 时间戳冻结在 turn 开始、Claude Code 三层前缀缓存、
   Codex content kinds——我们的「动态内容放消息尾部」方向一致,可加 kind 标签增强。
3. **压缩触发要估完整载荷**:Cline 估 system+messages+tools;Cline 阈值 0.9、char/token 保守 3。
   我们缺 tools(见 P0-15)。
4. **安全自治 = AI 审查 + 熔断 + fail-closed**:Codex Guardian、Claude Code 分类器模型、
   Cline overflow 确定性优先——多方共同模式。
