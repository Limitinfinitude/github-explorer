## 关键转折

1. **r8 归因（失败分类）**：shell 方言混用（CMD/PowerShell）→ 系统提示词规则 7；Python 解释器混乱 → 规则 8（ensure_venv 专用）；修复型任务轮次不足 → max_rounds 24→32。
2. **r9 归因**：验证器误伤（compileall 递归进 .venv）→ 排除规则；阶段预算过紧（inspect 24/implement 16 对真实应用不够）→ 36/24。
3. **提示词重构**（借鉴 Claude Code/OpenHands/Gemini）：环境上下文块（平台/shell/日期）、先规划后执行、探索-分析-实施-验证流程、失败列 3-5 因换思路、turn-budget 收敛标记、循环退一步提醒。
4. **消息流**（借鉴 Cline/pi）：usage 校准 token 估算、context overflow 强制压缩重试。
