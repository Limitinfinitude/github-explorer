# GitHub探索者 - 使用指南

## 快速开始

### 1. 配置API密钥

编辑项目根目录的 `.env` 文件：

```env
# GitHub Token (可选，但强烈建议配置)
# 获取地址: https://github.com/settings/tokens
# 无需勾选任何权限，仅用于提高API限制
GITHUB_TOKEN=your_github_token_here

# Claude API Key (AI解读功能必需)
# 获取地址: https://console.anthropic.com/
ANTHROPIC_API_KEY=your_anthropic_api_key_here
```

### 2. 启动服务

**Windows:**
```bash
双击 start.bat
# 或者
python src/main.py
```

**Mac/Linux:**
```bash
chmod +x start.sh
./start.sh
# 或者
python3 src/main.py
```

### 3. 访问应用

打开浏览器访问: http://localhost:8000

## 功能说明

### 搜索项目

1. 在搜索框输入关键词（如"机器学习"、"web框架"）
2. 选择编程语言筛选（可选）
3. 选择时间范围（7天/30天/90天）
4. 点击"搜索"按钮

### 查看热门飙升

页面加载后会自动显示近7天星数增长最快的项目。

### AI解读

点击项目卡片上的"AI解读"按钮，Claude会用通俗易懂的语言解释：
- 这个项目是什么
- 能做什么
- 适合谁使用
- 为什么受欢迎

### 克隆到本地

点击"克隆"按钮，项目会被下载到 `cloned_repos/` 目录，并自动生成启动脚本。

## 常见问题

### Q: 为什么搜索没有结果？

A: 可能原因：
- GitHub API限制（未配置Token时每小时60次请求）
- 网络问题
- 关键词太具体

### Q: AI解读功能不能用？

A: 需要配置 `ANTHROPIC_API_KEY` 环境变量。

### Q: 克隆失败？

A: 确保已安装Git并添加到PATH。
