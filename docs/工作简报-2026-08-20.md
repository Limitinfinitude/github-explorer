# GitHub Explorer 工作简报（2026-08-20）

> 本轮围绕 PRD v3.0「Agent 观测与实验工作台」方向，对项目工作台、侧边栏导航、主题外观做了四轮迭代。
> 全部为本地开发改动，前端构建产物 `src/web_dist` 已随构建更新；后端无新增依赖。

## 一、项目工作台功能完善（后端 + 前端）

目标：让工作台从"静态档案"变成"活的观测入口"，对齐 PRD P1 最小闭环。

### 后端
| 文件 | 内容 |
|---|---|
| `src/agent/memory.py` | 新增 `list_project_memories()`：无需 FTS 词条即可列出项目全部未过期事实 |
| `src/agent/runtime/project_projection.py` | 新增 `_failure_patterns()` 失败模式聚合（未恢复失败按「工具 + 错误首行」归类）；`build_project_overview` 增加 `failure_patterns` 字段；新增 `build_project_report_markdown()` 综合报告生成 |
| `src/routes_agent.py` | 新增 3 个端点：`GET /api/projects/{id}/memories`、`GET /api/projects/{id}/report`、`POST /api/projects/import`（绑定本地目录并立即启动项目体检，支持无历史任务的全新项目） |
| `tests/test_project_projection.py` | 补充 4 个单测（失败模式、错误行提取、overview 字段、报告渲染） |

### 前端（`ProjectWorkspaceView.tsx` 等）
- **实时刷新**：项目有运行/待确认任务时每 3 秒自动轮询概览，终态自动停止，显示最后更新时间。
- **项目记忆区块**：折叠展示任务完成后沉淀的项目事实（内容/验证徽章/置信度/来源）。
- **失败模式区块**：存在未恢复失败时展示「工具 × 次数 + 错误首行」摘要。
- **导出报告**：头部按钮下载综合 Markdown 报告。
- **空状态导入**：无项目时输入目录绝对路径即可导入并体检。

## 二、侧边栏重构：项目栏 + 任务栏（全部前端）

- 顶部按钮「新建任务」→ **「打开项目」**（跳转项目工作台视图）。
- **项目栏**（上侧）：列出项目目录，展开显示该项目下的**多个对话** +「新建对话」；项目头显示对话数徽章。
- **任务栏**（下方）：「新建任务」+ 未归属项目的普通任务/对话。
- **多对话按项目归属**：`Chat` 新增 `projectId`/`workspace` 元数据（`types.ts`、`chatState.ts`、`useChats.ts`）；后端零改动（工作区本就按 session 绑定、任务按 workspace_root 归属项目）。
- **工作区状态切换**：项目对话每次打开幂等绑定到项目目录（`ChatPanel.tsx`），修复了"新会话被兜底目录覆盖"的问题。

## 三、侧边栏折叠 + 快捷添加项目

- 项目栏/任务栏标题变为可折叠按钮（箭头旋转、`aria-expanded`），折叠时整个区块隐藏。
- 项目栏标题右侧新增「+」按钮，展开内联表单（目录路径 + 导入并体检），成功后自动展开新项目并刷新列表，失败显示后端校验错误。

## 四、浅色主题 + 切换开关

- **全站颜色收敛为语义变量**：`index.css` 定义深/浅两套变量（`:root` 深色、`:root[data-theme="light"]` 浅色，GitHub light 风格），脚本替换 **631 处**硬编码色值，根块外 0 残留；含 `color-scheme`。
- **JSX 硬编码 Tailwind 颜色类** → 变量工具类（`bg-canvas`/`text-fg`/`bg-surface-2`/`text-err` 等）。
- **主题机制**：`index.html` 首帧前内联脚本预置主题（刷新不闪白）；`App.tsx` 管理状态并持久化到 `localStorage.explorer_theme`。
- **切换开关**：设置页新增「外观主题」区块（深色/浅色分段开关），立即生效并持久化。
